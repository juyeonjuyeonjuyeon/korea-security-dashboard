# 주연뉴스 개인 번역 리더 설치

1. 데스크톱 Chrome 138 이상에서 `chrome://extensions`를 연다.
2. 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누른다.
4. 이 `extension` 폴더를 선택한다.
5. 주연뉴스에서 외국어 뉴스 제목을 누르고 **한국어 번역 시작**을 누른다.

확장 아이콘을 누르면 현재 보고 있는 일반 홈페이지도 주연뉴스 읽기모드로 보낼 수 있다. 확장은 원문을 숨은 탭에서 열어 실제 표시된 문서를 읽은 뒤 탭을 닫는다. 접근 제한이나 유료벽은 우회하지 않는다.
