# 주연상사뉴우스

공개 출처를 한 화면에 정리하는 개인·지인용 정적 PWA입니다. GitHub Pages와 GitHub Actions만 사용하므로 별도 서버비나 API 키가 필요하지 않습니다.

## 기능

- 조기경보 지표 10개, 복합 신호, 핵심 지표 5개
- 종합 위험도와 어제 대비 변화
- GDELT에서 주요 해외 보도 링크를 매일 수집
- 모바일 홈 화면 설치와 최근 화면 오프라인 열람
- 공식 확인, 관찰, 미확인을 구분한 보수적 표시

## 중요한 한계

자동 작업은 뉴스 링크를 수집할 뿐, 전쟁 가능성이나 군사 신호를 자동 확정하지 않습니다. ‘미확인’은 ‘없음’이 아닙니다. 실제 경보 시 대한민국 정부와 지자체의 공식 안내를 우선해야 합니다.

## 로컬 확인

정적 파일 서버로 이 폴더를 열면 됩니다. 서비스 워커는 `file://` 주소가 아니라 `http://localhost` 환경에서 작동합니다.

## 배포

GitHub Pages의 소스를 기본 브랜치 루트로 설정하면 됩니다. 자동 작업은 매일 한국 시간 오전 8시경 실행됩니다.
