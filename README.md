# 주연뉴스 — Korea Security Dashboard v2

공개 자료를 한 화면에 정리하는 정적 PWA입니다. GitHub Pages와 GitHub Actions만 사용하며 별도 서버비나 API 키가 필요하지 않습니다.

## 핵심 기능

- 종합 위험도, 오늘 점수, 어제 대비, 최근 7일 추세
- 오늘 달라진 위험신호와 공식 긴급경보 우선 표시
- 조기경보 지표 17개, 복합 위험 신호 8개, 핵심 지표 5개
- 7일·30일·90일 위험도 그래프와 날짜별 기록
- 한글 제목 뉴스 타임라인, 출처 등급, 공식 확인 여부, 해외 기사 번역 보기
- 루머 검증과 공개된 점수 산정 기준
- 종합 위험점수와 분리된 이상 징후·OSINT 보조 지수
- 이상지수 전일 변화·30일 추세와 항목별 근거·확인 시각
- 기술 7개 분야와 공식·주요 보도·전문 분석·커뮤니티 신호 4계층
- 1·2면 뉴스 검색·필터, 스크랩 백업·복원
- USGS 지진 관측과 공관·국제기구 공식 페이지 연결 상태
- 모바일 홈 화면 설치, 오프라인 최근 화면, 알림 조건 설정

## 위험도 산정

뉴스 개수로 점수를 올리지 않습니다. `config/risk-weights.json`에 정의된 가중치를 사용하며, 공식 발표가 있거나 신뢰할 수 있는 독립 출처 두 곳 이상이 같은 사건을 확인해야 점수에 반영합니다.

- 0–14: 평상시
- 15–29: 관심
- 30–49: 주의
- 50–69: 경계
- 70 이상: 심각

위험도와 별도로 판단 신뢰도(높음·중간·낮음)와 공개정보 완전성(0–100%)을 표시합니다. 기사 수가 아니라 독립 원정보를 세며, 발령 권한이 있는 공식기관의 직접 공지 또는 독립된 신뢰 가능한 원정보 2개 이상이 확인될 때 위험도에 반영합니다. 공개자료상 미탐지와 직접 관측 부족, 수집 실패는 서로 다른 상태로 보존합니다.

자동 판정은 공개 자료를 빠르게 정리하기 위한 참고 정보입니다. 실제 경보는 재난문자, 합동참모본부, 국방부, 행정안전부 등 공식 발표를 우선해야 합니다.

## 자동 갱신

GitHub Actions가 매일 한국 시간 오전 6시와 오후 6시에 전체 자료를 갱신하고, 기술 공식 채널은 매시간 새 글 여부를 확인합니다. 안보면은 38 North, Beyond Parallel, Arms Control Wonk, ISW, Bellingcat, Stimson 등 OSINT·전문 분석을 공식 경보와 분리해 제공합니다. 기술면은 공식 원문, 주요 언론, 전문가 분석, 커뮤니티 관심 신호를 구분합니다. 수집에 실패하면 마지막 정상 데이터를 유지합니다.

## 로컬 확인

정적 파일 서버에서 프로젝트 루트를 열면 됩니다. PWA 기능은 `file://` 주소가 아닌 `localhost` 또는 HTTPS에서 작동합니다.

## 배포

`main` 브랜치를 GitHub Pages로 배포합니다. 서비스 워커와 매니페스트는 저장소 하위 경로에서도 동작하도록 상대 경로를 사용합니다.
